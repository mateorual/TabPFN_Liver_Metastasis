# Section 6: Models fitted to transformed data

This folder reapplies the reference diagnostic and prognostic workflows to two
TabPFN-derived representations:

- `embedding/`: models fitted to supervised embedding variables;
- `synthetic/`: models fitted to the complete generated cohorts.

Each diagnostic or prognostic subfolder is an independent R pipeline. The
machine-readable summaries and report figures are under
`results/06_transformed_data_models/`.
