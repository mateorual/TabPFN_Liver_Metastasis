# Section 7: Similarity and synthetic-data fidelity

`similarity_metrics/` measures distributional and structural similarity and
creates the dimensionality-reduction views. `deep_synthetic_validation/`
evaluates category support, survival-curve preservation, interactions,
conditional dependence, subgroup behaviour, and model transfer.

The active analysis uses only the complete joint synthetic cohorts. Compact
results are under `results/07_similarity_and_fidelity/`.
