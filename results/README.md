# Curated results

Results are organised by report section. Each folder contains only aggregate
tables, figures, validation summaries, or compact manifests that support the
final report. Per-patient predictions, bootstrap membership rows, model
checkpoints, and training logs are deliberately omitted.

Where available, `report_tables/` contains the compact values shown in the
report, while `aggregate_tables/` contains the corresponding machine-readable
analysis summaries. The definitive interpretation of these results is given in
`../report/final_report.pdf`.
